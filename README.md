# clean-dark-ui

A Claude skill for building apps and pages that look designer-made, not "AI". Clean dark look in the spirit of Apple-style product design: small corners, few greys, one accent colour, plain fonts, inbox-style lists, and playful moments that stay tasteful.

## Install

**Claude app (claude.ai / desktop)**
1. Download this repo as a ZIP (green **Code** button, then **Download ZIP**).
2. Unzip it and zip just the `clean-dark-ui` folder inside.
3. In Claude, go to Settings, then Capabilities (Skills), and upload that ZIP.

**Claude Code**
Copy the `clean-dark-ui` folder into `~/.claude/skills/`.

## Use

Just ask Claude to build or restyle a UI. The skill kicks in on its own. You can also say "use the clean-dark-ui skill".

What's inside: `clean-dark-ui/SKILL.md`
